# Nexus Engine - Unity 게임 개발 프레임워크

## 프로젝트 개요

Nexus Engine은 XSBD에서 개발한 Unity 기반 게임 개발 프레임워크입니다. 
고성능 ECS 아키텍처와 직관적인 API를 제공하여 게임 개발을 가속화합니다.

---

## 주요 기능

- 🚀 **고성능 ECS 시스템** - 대규모 엔티티 관리
- 🎨 **직관적인 렌더링 파이프라인** - 커스텀 셰이더 지원
- 🔧 **확장 가능한 플러그인 아키텍처**
- 📊 **실시간 프로파일링 도구**

## 기술 스택

- **엔진:** Unity 2022 LTS
- **언어:** C#
- **아키텍처:** ECS Pattern
- **렌더링:** URP (Universal Render Pipeline)

## 설치 및 사용

```bash
git clone https://github.com/swddoram/nexus-engine.git
cd nexus-engine
npm install
```
